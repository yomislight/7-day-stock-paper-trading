# 7 天股票交易实验：开始使用

这个文件夹是项目工作目录。策略、配置、检查脚本、状态和后续记录都放在这里。

完整目录见 [项目首页](../README.md)，当前决定与待办见 [项目交接说明](../02-项目文档-docs/PROJECT-HANDOFF.zh-CN.md)。最新结果以 `04-运行状态-state/readiness.json` 为准。

## 1. 填写币安 API

用文本编辑器打开根目录的 `10-API密钥-仅本地-local-secrets/binance-api.env`，在本机填写两项：

```env
BINANCE_API_KEY=
BINANCE_API_SECRET=
BINANCE_ENV=production
```

使用 HMAC 类型密钥，启用读取权限。`production` 表示读取正式账户，检查脚本只发送 GET 请求。股票实验仍保持模拟模式。`testnet` 仅可用于 Spot 诊断，不能验证股票接口。

此脚本只读取本项目的 `10-API密钥-仅本地-local-secrets/binance-api.env`，不读取其他项目、系统环境变量或旧 `.env`。文件中不要添加行末注释；注释请单独写一行。

## 2. 检查连接

需要 Python 3.9 或更新版本，无需安装第三方 Python 包。在终端运行：

```bash
cd "/Users/a123/Desktop/7天股票交易实验"
python3 06-程序脚本-scripts/binance_readiness_check.py --update-readiness
```

`stock_etf_access_verified: true` 表示股票标的规则、报价及未完成订单读取均通过。`signed_account_read_verified` 单独表示 Spot 账户诊断结果。密钥已填写不等于认证成功，读取成功也不等于实盘交易就绪。

尚未填写密钥时，也可先检查公共连接：

```bash
python3 06-程序脚本-scripts/binance_readiness_check.py --public-only
```

退出码：0 为本次检查成功；2 为密钥缺失或账户验证失败；3 为公共连接失败；4 为本地文件缺失或格式错误。

HTTP 401/403 时检查密钥权限、IP 白名单、账户环境及服务可用性；网络错误时检查网络连接。错误输出不包含密钥、签名、账户余额或原始响应。

## 3. 结果意味着什么

检查结果写入 `04-运行状态-state/readiness.json` 的 `binance_stocks_api` 节点，并更新股票 API 读取验证项。它有自己的检查时间，不会刷新全部资格检查。`orders_allowed` 保持 false。

本脚本已改为币安 Stocks API，并单独查询 API 权限。账户的 `canTrade` 字段不能单独证明某个 API Key 的权限。地区资格、行情新鲜度、股票账户持仓和结算现金仍需另外核验。

接口说明见 `02-项目文档-docs/BINANCE-API.zh-CN.md`；本地 paper 账本已经执行仓位、点差、费用、止损和目标规则，但不提供连续监控。

## 运行记录与恢复

`python3 -B 06-程序脚本-scripts/run_observation.py --manual` 执行一次只读检查，写入 SQLite、journal、evidence 和 current-state。

`python3 -B 06-程序脚本-scripts/run_observation.py --dry-run` 只判断是否到达六个研究时点，不访问账户、不写文件。第二轮实验日期为 2026-09-24、09-25、09-28、09-29、09-30、10-01、10-02。

## 补充分钟成交量和 VWAP

新开模拟仓位前，系统会自动读取无密钥公共五分钟 K 线，并计算成交量背景和推导 VWAP，不需要注册 Alpaca 或填写第二组 API Key。完整边界见[无密钥辅助量价数据](../02-项目文档-docs/PUBLIC-MARKET-DATA.zh-CN.md)。公共数据缺失、过期或结构变化时，系统会正常观察和报告，但不会新开模拟仓位。

## 检查七天完成度

```bash
python3 -B 06-程序脚本-scripts/experiment_status.py
```

只有 `fully_completed_trading_days` 为 7 且 `experiment_complete` 为 true，才算跑满七天。

`python3 -B 06-程序脚本-scripts/run_observation.py --recover` 在获得进程锁后将中断的只读运行标记为 interrupted，并重新导出已完成日志；不会重发订单或回滚持仓。只读运行记录保存在 SQLite，模拟成交事件保存在独立 paper ledger；系统不提供连续风险监控。
