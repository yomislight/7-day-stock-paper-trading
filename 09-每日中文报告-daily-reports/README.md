# 每日中文报告

这里是给人直接阅读的交易结果，不需要理解 JSON、SQLite 或英文运行日志。

每个美国交易日对应一份 `YYYY-MM-DD-每日交易报告.md`，内容包括：

- 当天是否模拟买入或卖出
- 当天主要股指表现、利率、油价、市场主线和对策略的影响
- 当前现金、总资产和持仓
- 当天已实现与未实现盈亏
- 每次检查为什么交易或不交易
- 为什么买入或没有买入，为什么卖出或没有卖出
- 哪些检查按时完成，哪些检查漏跑或延迟
- 当日做对了什么、哪里不足，以及需要共同修改什么
- 当前风险、下一步和真实交易安全状态

底层 `journal/`、`evidence/`、`decisions/` 和数据库继续保留，用于审计与复盘。
